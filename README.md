# 🍅 Pomodoro Timer CLI

A clean and simple **Pomodoro Timer** built using Python.
This command-line tool helps users stay focused by working in timed intervals using the **Pomodoro Technique**.

---

## 🚀 Features

* ⏳ Countdown timer displayed in the terminal
* 🧠 Helps improve productivity and focus
* ⚡ Lightweight and fast
* 💻 Runs directly in the command line
* 🐍 Built with pure Python (no external libraries)

---

## 🖥️ Example Output

```
Welcome to the Pomodoro Timer

Enter time in minutes: 25

Time Remaining: 24:59
Time Remaining: 24:58
Time Remaining: 24:57
...
Time's up! Take a break.
```

---

## ⚙️ How to Run

Make sure you have **Python installed**, then run:

```
python pomodoro_timer.py
```
